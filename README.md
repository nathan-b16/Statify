# Statify (Spotify Stats) 🎵

A full-stack web application that handles user authentication and processes personal Spotify metrics to deliver insights into your listening habits.
statify-web-app-fqbeeyb3gsedc9a4.israelcentral-01.azurewebsites.net
## 🚀 Tech Stack

*   **Frontend:** HTML + CSS + Charts.js
*   **Backend:** Java Spring Boot
*   **Database:** MySQL
*   **Integration:** Spotify Web API + ReccoBeats API

## ✨ Features

*   **Secure Authentication:** Seamless user login and session handling.
*   **Metrics Processing:** Aggregates and processes raw listening data into readable metrics.
*   **Feature:** Top Artists & Tracks visualization
